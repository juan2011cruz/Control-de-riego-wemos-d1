# Control-de-riego-wemos-d1
Sistema inteligente de riego automático basado en ESP8266 (Wemos D1 mini), con control de bomba y sectores, programación horaria, interfaz web, sincronización NTP, modos Cliente y Punto de Acceso Wi-Fi, control manual, indicadores LED y funcionamiento autónomo con prioridad de llenado de tanque y protecciones integradas.
